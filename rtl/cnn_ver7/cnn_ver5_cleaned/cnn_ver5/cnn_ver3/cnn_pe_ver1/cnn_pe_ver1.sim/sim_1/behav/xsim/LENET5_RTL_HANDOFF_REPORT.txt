5. CHOT START / DMA / SLIDING-WINDOW / FC
--------------------------------------------------------------------------
START:
- RISC-V phat start trong 1 clock khi busy=0.
- Mot assertion start chi duoc nhan mot lan. Start khi busy=1 bi tu choi;
  giu start=1 khong tao request tre/retrigger. Muon request moi phai ha start
  roi phat lai sau khi busy=0.

DMA:
- Moi frame co 2 pulse dma_start: layer_select=00 cho Conv1, sau do 01 Conv2.
- dma_done la ACK "nguon du lieu/config da san sang", khong phai beat AXI.
- Moi request can mot assertion dma_done rieng; dma_done phai ha thap giua
  hai ACK. Scheduler khong tai su dung mot muc done cu cho lop tiep theo.

SLIDING WINDOW:
- sw_load_en la level-enable, giu high trong RUN va WAIT_LAYER_DONE.
- sw_cfg/layer_select giu 00 cho Conv1 (28x28x1), 01 cho Conv2 (13x13x8).
- Pool1 duoc luu vao RAM cuc bo 169x64 bit va replay du 169 beat cho Conv2.
- Replay Conv2 da khoi dong se drain du 169 beat, ke ca khi Pool2 da phat
  25 output va scheduler chuyen sang FC. Vi vay Conv2 van cho du 121 window.

LAYER DONE:
- Conv1: pulse 1 clock sau du 169 p1_valid.
- Conv2: pulse 1 clock sau du 25 p2_valid.

FC:
- fc_stream thu du 25 vector Pool2 x 24 kenh truoc.
- Sau do WAIT_FC_START; fc_start duoc latch neu den som.
- fc_done = fc_stream.valid_out, pulse 1 clock khi class da duoc latch.


6. CHOT TVALID / TREADY / TLAST
--------------------------------------------------------------------------
Input transfer tai rising edge khi:
    s_axis_tvalid && s_axis_tready

- Mot frame co dung 784 handshake.
- Khong co input TLAST; compute engine dem 784 transfer.
- Source giu TVALID va TDATA on dinh khi TREADY=0.
- TREADY chi mo trong pha Conv1 da duoc scheduler cho phep.

Output transfer tai rising edge khi:
    m_axis_tvalid && m_axis_tready

- Mot frame co mot output beat.
- m_axis_tdata[5:0] = class 0..46; [7:6] = 00.
- m_axis_tlast = m_axis_tvalid.
- Khi TREADY=0, TDATA/TVALID/TLAST duoc giu on dinh den handshake.


7. DONE / BUSY / PREDICTION_READY / CLASS
--------------------------------------------------------------------------
- done va prediction_ready la STICKY LEVEL, khong phai pulse.
- Chung duoc set trong FINISH va giu den start moi duoc chap nhan.
- error sticky trong ERROR_STATE den khi reset.
- busy bao gom thoi gian compute va ca output AXI dang cho duoc nhan.
- Khi output bi backpressure, done=1/prediction_ready=1 va busy=1 co the
  cung ton tai: ket qua da tinh xong nhung transaction chua ket thuc.
- RISC-V/host phai nhan output, doi busy=0, sau do moi phat start moi.
- Class duoc tra qua AXI-Stream master, khong co class-register port rieng.

9. RANH GIOI TICH HOP VOI NHOM 2
--------------------------------------------------------------------------
Bo tai lieu ban dau chi dinh control dma_start/dma_done/layer_select, khong
dinh nghia data bus 64-bit tu Memory den Conv2. Vi vay ban Group-1 nay dung
RAM P1 cuc bo lam cau noi chuc nang cho 169x64-bit feature map.

Khi thay bang Memory Group-2 that, can chot them data/valid/ready (toi thieu
64 bit cho Conv2), thu tu kenh [c*8 +: 8], dia chi/length va backpressure.
Khong duoc hieu dma_done la ket thuc transfer tren cung AXI input 8-bit;
trong top hien tai no co nghia nguon/config da san sang de compute bat dau.
